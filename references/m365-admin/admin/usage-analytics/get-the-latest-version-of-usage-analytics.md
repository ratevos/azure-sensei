# Get the latest version of Microsoft 365 usage analytics

> Source: https://learn.microsoft.com/en-us/microsoft-365/admin/usage-analytics/get-the-latest-version-of-usage-analytics  
> Microsoft doc last updated: 02/19/2020


The template app may be refreshed with new data or new visualizations several times per year. Your existing instance will continue to work, but if you would like to get the latest version, a new instance must be created and any customizations must be applied to the new instance. See [Enable Microsoft 365 usage analytics](https://learn.microsoft.com/en-us/microsoft-365/admin/usage-analytics/enable-usage-analytics).
