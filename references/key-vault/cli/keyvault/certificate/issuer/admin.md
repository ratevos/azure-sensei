# az keyvault certificate issuer admin

> Source: https://learn.microsoft.com/en-us/cli/azure/keyvault/certificate/issuer/admin  
> Microsoft doc last updated: unknown

Manage admin information for certificate issuers.

Subgroups and commands: `az_keyvault_certificate_issuer_admin_add`, `az_keyvault_certificate_issuer_admin_delete`, `az_keyvault_certificate_issuer_admin_list`

## az keyvault certificate issuer admin add

Add admin details for a specified certificate issuer.

**Required parameters**

- `--email` — Admin e-mail address. Must be unique within the vault.
- `--issuer-name` — Certificate issuer name.
- `--vault-name` — Name of the Vault.

**Optional parameters**

- `--acquire-policy-token` — Acquiring an Azure Policy token automatically for this resource operation.
- `--change-reference` — The related change reference ID for this resource operation.
- `--first-name` — Admin first name.
- `--last-name` — Admin last name.
- `--phone` — Admin phone number.

*Add a new certificate issuer administrator to a Key Vault by specifying the vault, issuer name, and admin email. (autogenerated)*
```azurecli
az keyvault certificate issuer admin add --vault-name cli-mock-kv-ct-is --issuer-name issuer1 --email mock2@mock.com
```

## az keyvault certificate issuer admin delete

Remove admin details for the specified certificate issuer.

**Required parameters**

- `--email` — Admin e-mail address. Must be unique within the vault.
- `--issuer-name` — Certificate issuer name.
- `--vault-name` — Name of the Vault.

**Optional parameters**

- `--acquire-policy-token` — Acquiring an Azure Policy token automatically for this resource operation.
- `--change-reference` — The related change reference ID for this resource operation.

## az keyvault certificate issuer admin list

List admins for a specified certificate issuer.

**Required parameters**

- `--issuer-name` — Certificate issuer name.
- `--vault-name` — Name of the Vault.
