# az ad sp

> Source: https://learn.microsoft.com/en-us/cli/azure/ad/sp  
> Microsoft doc last updated: unknown

Manage Microsoft Entra service principals.

Subgroups and commands: `az_ad_sp_create`, `az_ad_sp_create-for-rbac`, `az_ad_sp_credential`, `az_ad_sp_credential_delete`, `az_ad_sp_credential_list`, `az_ad_sp_credential_reset`, `az_ad_sp_delete`, `az_ad_sp_list`, `az_ad_sp_owner`, `az_ad_sp_owner_list`, `az_ad_sp_show`, `az_ad_sp_update`

## az ad sp create

Create a service principal.

**Required parameters**

- `--id` — Identifier uri, application id, or object id of the associated application.

**Optional parameters**

- `--acquire-policy-token` — Acquiring an Azure Policy token automatically for this resource operation.
- `--change-reference` — The related change reference ID for this resource operation.

*Create a service principal. (autogenerated)*
```azurecli
az ad sp create --id 00000000-0000-0000-0000-000000000000
```

## az ad sp create-for-rbac

Create an application and its associated service principal, optionally configure the service principal's RBAC role assignments.

**Optional parameters**

- `--acquire-policy-token` — Acquiring an Azure Policy token automatically for this resource operation.
- `--cert` — Certificate to use for credentials. When used with `--keyvault,`, indicates the name of the cert to use or create. Otherwise, supply a PEM or DER formatted public certificate string. Use `@{path}` to load from a file. Do not include the private key.
- `--change-reference` — The related change reference ID for this resource operation.
- `--create-cert` — Create a self-signed certificate to use for the credential. Only the current OS user has read/write permission to this certificate. Use with `--keyvault` to create the certificate in Key Vault. Otherwise, a certificate will be created locally. Default: False.
- `--create-password` — Create a password credential (secret) on the the application. This is the default behavior. Set this argument to false to disable creating password credential. Default: True.
- `--display-name --name -n` — Display name of the service principal. If not present, default to azure-cli-%Y-%m-%d-%H-%M-%S where the suffix is the time of creation.
- `--json-auth --sdk-auth` — Output service principal credential along with cloud endpoints in JSON format.
- `--keyvault` — Name or ID of a KeyVault to use for creating or retrieving certificates.
- `--role` — Role of the service principal.
- `--scopes` — Space-separated list of scopes the service principal's role assignment applies to. e.g., subscriptions/0b1f6471-1bf0-4dda-aec3-111122223333/resourceGroups/myGroup, /subscriptions/0b1f6471-1bf0-4dda-aec3-111122223333/resourceGroups/myGroup/providers/Microsoft.Compute/virtualMachines/myVM.
- `--service-management-reference` — Set the serviceManagementReference property of the created application. Reference application or service contact information from a Service or Asset Management database.
- `--years` — Number of years for which the credentials will be valid. Default: 1 year.

*Create without role assignment.*
```azurecli
az ad sp create-for-rbac
```

*Create using a custom display name.*
```azurecli
az ad sp create-for-rbac -n MyApp
```

*Create with a Contributor role assignments on specified scopes. To retrieve current subscription ID, run `az account show --query id --output tsv`.*
```azurecli
az ad sp create-for-rbac -n MyApp --role Contributor --scopes /subscriptions/00000000-0000-0000-0000-000000000000/resourceGroups/resourceGroup1 /subscriptions/00000000-0000-0000-0000-000000000000/resourceGroups/resourceGroup2
```

*Do not create password credential.*
```azurecli
az ad sp create-for-rbac --create-password false
```

*Create using a self-signed certificate.*
```azurecli
az ad sp create-for-rbac --create-cert
```

*Create using an existing certificate string.*
```azurecli
az ad sp create-for-rbac --cert "MIICoT..."
```

*Create using an existing certificate file.*
```azurecli
az ad sp create-for-rbac --cert "@~/cert.pem"
`cert.pem` contains the following content
-----BEGIN CERTIFICATE-----  <<< this line is optional
MIICoT...
-----END CERTIFICATE-----    <<< this line is optional
```

*Create using a self-signed certificate, and store it within Azure Key Vault.*
```azurecli
az ad sp create-for-rbac --keyvault MyVault --cert CertName --create-cert
```

*Create using existing certificate in Azure Key Vault.*
```azurecli
az ad sp create-for-rbac --keyvault MyVault --cert CertName
```

## az ad sp delete

Delete a service principal.

**Required parameters**

- `--id` — Service principal name, or object id.

**Optional parameters**

- `--acquire-policy-token` — Acquiring an Azure Policy token automatically for this resource operation.
- `--change-reference` — The related change reference ID for this resource operation.

*Delete a service principal.*
```azurecli
az ad sp delete --id 00000000-0000-0000-0000-000000000000
```

## az ad sp list

List service principals.

**Optional parameters**

- `--all` — List all entities, expect long delay if under a big organization.
- `--display-name` — Object's display name or its prefix.
- `--filter` — OData filter, e.g. --filter "displayname eq 'test' and servicePrincipalType eq 'Application'".
- `--show-mine` — List entities owned by the current user.
- `--spn` — Service principal name.

## az ad sp show

Get the details of a service principal.

**Required parameters**

- `--id` — Service principal name, or object id.

*Get the details of a service principal with appId.*
```azurecli
az ad sp show --id 00000000-0000-0000-0000-000000000000
```

*Get the details of a service principal with id.*
```azurecli
az ad sp show --id 00000000-0000-0000-0000-000000000000
```

*Get the details of a service principal with identifier URI.*
```azurecli
az ad sp show --id api://myapp
```

## az ad sp update

Update a service principal.

**Required parameters**

- `--id` — Service principal name, or object id.

**Optional parameters**

- `--acquire-policy-token` — Acquiring an Azure Policy token automatically for this resource operation.
- `--add` — Add an object to a list of objects by specifying a path and key value pairs. Example: `--add property.listProperty <key=value, string or JSON string>`. Default: [].
- `--change-reference` — The related change reference ID for this resource operation.
- `--force-string` — When using 'set' or 'add', preserve string literals instead of attempting to convert to JSON. Default: False.
- `--remove` — Remove a property or an element from a list. Example: `--remove property.list <indexToRemove>` OR `--remove propertyToRemove`. Default: [].
- `--set` — Update an object by specifying a property path and value to set. Example: `--set property1.property2=<value>`. Default: [].

*update a service principal (autogenerated)*
```azurecli
az ad sp update --id 00000000-0000-0000-0000-000000000000 --set groupMembershipClaims=All
```
