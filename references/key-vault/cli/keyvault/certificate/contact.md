# az keyvault certificate contact

> Source: https://learn.microsoft.com/en-us/cli/azure/keyvault/certificate/contact  
> Microsoft doc last updated: unknown

Manage contacts for certificate management.

Subgroups and commands: `az_keyvault_certificate_contact_add`, `az_keyvault_certificate_contact_delete`, `az_keyvault_certificate_contact_list`

## az keyvault certificate contact add

Add a contact to the specified vault to receive notifications of certificate operations.

**Required parameters**

- `--email` — Contact e-mail address. Must be unique.
- `--vault-name` — Name of the Vault.

**Optional parameters**

- `--acquire-policy-token` — Acquiring an Azure Policy token automatically for this resource operation.
- `--change-reference` — The related change reference ID for this resource operation.
- `--name` — Full contact name.
- `--phone` — Contact phone number.

*Add a certificate contact with the specified email to the Key Vault. (autogenerated)*
```azurecli
az keyvault certificate contact add --vault-name cli-mock-kv-ct-co --email other@contoso.com
```

## az keyvault certificate contact delete

Remove a certificate contact from the specified vault.

**Required parameters**

- `--email` — Contact e-mail address. Must be unique.
- `--vault-name` — Name of the Vault.

**Optional parameters**

- `--acquire-policy-token` — Acquiring an Azure Policy token automatically for this resource operation.
- `--change-reference` — The related change reference ID for this resource operation.

## az keyvault certificate contact list

Lists the certificate contacts for a specified key vault.

**Required parameters**

- `--vault-name` — Name of the Vault.
