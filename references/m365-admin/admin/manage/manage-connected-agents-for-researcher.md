# Manage connected agents for Researcher in Microsoft 365 admin center

> Source: https://learn.microsoft.com/en-us/microsoft-365/admin/manage/manage-connected-agents-for-researcher  
> Microsoft doc last updated: 11/18/2025


> [!IMPORTANT]
>
> This feature is in the process of rolling out and might not be available in your region yet.

The **Connected Agents** tab for Researcher allows administrators to link additional agents that can provide information and answers when users interact with Researcher. This helps extend Researcher's capabilities by leveraging other agents within your organization.

## What Are Connected Agents

Connected agents are other Copilot-enabled agents that can share data or insights with Researcher. When connected, users can query Researcher and receive responses that include information from these linked agents.

## Key Details

- **Limit** - Up to 10 agents can be connected to Researcher by admins.
- **Exclusions** - Agents added by the maker cannot be removed by admins.
- **Access** - Ensure connected agents are available to everyone who needs access.

## How to Connect Agents

1. In the [Microsoft 365 admin center](https://admin.microsoft.com/), navigate to **Agents** > **All agents**.

1. Select **Researcher** and then go to the **Connected Agents** tab.

    

1. Select **+ Connect agents**.

1. In the **Select agent to connect** panel:

   - Use the search bar to find agents.

   - Check the box next to the agents you want to connect.

1. Select **Save** to confirm.

## Managing Connected Agents

- **Remove an Agent** - From the Connected Agents list, select the agent and select **Remove**.
- **Reset to Default** - Use this option to clear all custom connections and revert to the default state.
