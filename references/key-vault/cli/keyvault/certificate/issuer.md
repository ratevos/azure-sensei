# az keyvault certificate issuer

> Source: https://learn.microsoft.com/en-us/cli/azure/keyvault/certificate/issuer  
> Microsoft doc last updated: unknown

Manage certificate issuer information.

Subgroups and commands: `az_keyvault_certificate_issuer_admin`, `az_keyvault_certificate_issuer_admin_add`, `az_keyvault_certificate_issuer_admin_delete`, `az_keyvault_certificate_issuer_admin_list`, `az_keyvault_certificate_issuer_create`, `az_keyvault_certificate_issuer_delete`, `az_keyvault_certificate_issuer_list`, `az_keyvault_certificate_issuer_show`, `az_keyvault_certificate_issuer_update`

## az keyvault certificate issuer create

Create a certificate issuer record.

**Required parameters**

- `--issuer-name` — Certificate issuer name.
- `--provider-name` — The certificate provider name. Must be registered with your tenant ID and in your region.
- `--vault-name` — Name of the Vault.

**Optional parameters**

- `--account-id` — The issuer account id/username/etc.
- `--acquire-policy-token` — Acquiring an Azure Policy token automatically for this resource operation.
- `--change-reference` — The related change reference ID for this resource operation.
- `--disabled` — Set issuer to disabled state.
- `--organization-id` — The organization id.
- `--password` — The issuer account password/secret/etc.

*Create a certificate issuer in a Key Vault by specifying vault name, issuer name, and provider. (autogenerated)*
```azurecli
az keyvault certificate issuer create --vault-name cli-mock-kv-ct-is --issuer-name issuer1 --provider Test
```

## az keyvault certificate issuer delete

Deletes the specified certificate issuer.

**Required parameters**

- `--issuer-name` — Certificate issuer name.
- `--vault-name` — Name of the Vault.

**Optional parameters**

- `--acquire-policy-token` — Acquiring an Azure Policy token automatically for this resource operation.
- `--change-reference` — The related change reference ID for this resource operation.

## az keyvault certificate issuer list

Lists properties of the certificate issuers for the key vault.

**Required parameters**

- `--vault-name` — Name of the Vault.

## az keyvault certificate issuer show

Gets the specified certificate issuer.

**Required parameters**

- `--issuer-name` — Certificate issuer name.
- `--vault-name` — Name of the Vault.

## az keyvault certificate issuer update

Update a certificate issuer record.

**Required parameters**

- `--issuer-name` — Certificate issuer name.
- `--vault-name` — Name of the Vault.

**Optional parameters**

- `--account-id` — The issuer account id/username/etc.
- `--acquire-policy-token` — Acquiring an Azure Policy token automatically for this resource operation.
- `--change-reference` — The related change reference ID for this resource operation.
- `--enabled` — Set issuer enabled state.
- `--organization-id` — The organization id.
- `--password` — The issuer account password/secret/etc.
- `--provider-name` — The certificate provider name. Must be registered with your tenant ID and in your region.
