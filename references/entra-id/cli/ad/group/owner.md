# az ad group owner

> Source: https://learn.microsoft.com/en-us/cli/azure/ad/group/owner  
> Microsoft doc last updated: unknown

Manage group owners.

Subgroups and commands: `az_ad_group_owner_add`, `az_ad_group_owner_list`, `az_ad_group_owner_remove`

## az ad group owner add

Add a group owner.

**Required parameters**

- `--group -g` — Group's object id or display name(prefix also works if there is a unique match).
- `--owner-object-id` — Owner's object id.

**Optional parameters**

- `--acquire-policy-token` — Acquiring an Azure Policy token automatically for this resource operation.
- `--change-reference` — The related change reference ID for this resource operation.

*add a group owner. (autogenerated)*
```azurecli
az ad group owner add --group MyGroupDisplayName --owner-object-id xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```
