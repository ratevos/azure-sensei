# az ad app owner

> Source: https://learn.microsoft.com/en-us/cli/azure/ad/app/owner  
> Microsoft doc last updated: unknown

Manage application owners.

Subgroups and commands: `az_ad_app_owner_add`, `az_ad_app_owner_list`, `az_ad_app_owner_remove`

## az ad app owner add

Add an application owner.

**Required parameters**

- `--id` — Identifier uri, application id, or object id.
- `--owner-object-id` — Owner's object id.

**Optional parameters**

- `--acquire-policy-token` — Acquiring an Azure Policy token automatically for this resource operation.
- `--change-reference` — The related change reference ID for this resource operation.

*add an application owner. (autogenerated)*
```azurecli
az ad app owner add --id 00000000-0000-0000-0000-000000000000 --owner-object-id xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

## az ad app owner list

List application owners.

**Required parameters**

- `--id` — Identifier uri, application id, or object id of the application.

*List application owners. (autogenerated)*
```azurecli
az ad app owner list --id 00000000-0000-0000-0000-000000000000
```

**Optional parameters**

- `--acquire-policy-token` — Acquiring an Azure Policy token automatically for this resource operation.
- `--change-reference` — The related change reference ID for this resource operation.
