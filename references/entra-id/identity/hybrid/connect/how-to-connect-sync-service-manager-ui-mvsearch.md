# The Microsoft Entra Connect Sync Service Manager Metaverse Search| Microsoft Docs'

> Source: https://learn.microsoft.com/en-us/entra/identity/hybrid/connect/how-to-connect-sync-service-manager-ui-mvsearch  
> Microsoft doc last updated: 04/09/2025


The metaverse search tab is useful for troubleshooting data-related problems. In the top half, you can create a query based on a combination of attributes. When you are satisfied with your query, click **Search**. The result is visible in the bottom grid. You can select which columns should be visible with **Column Settings**.

In the search results, select an object and **Properties** to see the [metaverse object properties](https://learn.microsoft.com/en-us/entra/identity/hybrid/connect/tshoot-connect-object-not-syncing#metaverse-object-properties).
