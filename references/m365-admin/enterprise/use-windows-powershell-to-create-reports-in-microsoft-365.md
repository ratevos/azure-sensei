# Use PowerShell to create reports for Microsoft 365

> Source: https://learn.microsoft.com/en-us/microsoft-365/enterprise/use-windows-powershell-to-create-reports-in-microsoft-365  
> Microsoft doc last updated: 06/27/2024


*This article applies to both Microsoft 365 Enterprise and Office 365 Enterprise.*

Many different reports are available in the Microsoft 365 admin center. But these reports only provide so much information, and sometimes you need more. That's when you need PowerShell for Microsoft 365.
  
These articles describe how to use PowerShell for Microsoft 365 to get information from your Microsoft 365 tenant:
  
- Get started with reporting using PowerShell for Microsoft 365:

  - [Why you need to use PowerShell for Microsoft 365](https://learn.microsoft.com/en-us/microsoft-365/enterprise/why-you-need-to-use-microsoft-365-powershell)

- Reports for user accounts and licenses:

  - [View Microsoft 365 licenses and services with PowerShell](https://learn.microsoft.com/en-us/microsoft-365/enterprise/view-licenses-and-services-with-microsoft-365-powershell)

  - [View Microsoft 365 licensed and unlicensed users with PowerShell](https://learn.microsoft.com/en-us/microsoft-365/enterprise/view-licensed-and-unlicensed-users-with-microsoft-365-powershell)

  - [View Microsoft 365 account license and service details with PowerShell](https://learn.microsoft.com/en-us/microsoft-365/enterprise/view-account-license-and-service-details-with-microsoft-365-powershell)

  - [View Microsoft 365 user accounts with PowerShell](https://learn.microsoft.com/en-us/microsoft-365/enterprise/view-user-accounts-with-microsoft-365-powershell)

- Reports for SharePoint:

  - [Get started with SharePoint Management Shell](https://learn.microsoft.com/en-us/powershell/sharepoint/sharepoint-online/connect-sharepoint-online)

  - [Get-SPOSiteGroup - Gets all the groups on a specified site collection](https://learn.microsoft.com/en-us/powershell/module/microsoft.online.sharepoint.powershell/get-spositegroup)

- Reports for Exchange Online:

  - [Use Exchange Online PowerShell to display mailbox](https://learn.microsoft.com/en-us/exchange/recipients-in-exchange-online/manage-user-mailboxes/use-powershell-to-display-mailbox-information)
