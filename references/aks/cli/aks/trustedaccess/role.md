# az aks trustedaccess role

> Source: https://learn.microsoft.com/en-us/cli/azure/aks/trustedaccess/role  
> Microsoft doc last updated: unknown

Commands to manage trusted access roles.

Subgroups and commands: `az_aks_trustedaccess_role_list`

## az aks trustedaccess role list

List trusted access roles.

**Required parameters**

- `--location -l` — Location. Values from: `az account list-locations`. You can configure the default location using `az configure --defaults location=<location>`.
