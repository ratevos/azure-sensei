# az keyvault ekm-connection certificate

> Source: https://learn.microsoft.com/en-us/cli/azure/keyvault/ekm-connection/certificate  
> Microsoft doc last updated: unknown

Manage EKM proxy certificate information.

Subgroups and commands: `az_keyvault_ekm-connection_certificate_show`

## az keyvault ekm-connection certificate show

Show the EKM proxy client certificate.

**Optional parameters**

- `--hsm-name` — Name of the HSM. Can be omitted if --id is specified.
- `--id` — Full URI of the HSM.
